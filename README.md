# 🏛️ MFE Mantenimiento y Catálogos • EduPortal Microfrontend Remoto

> **Dominio:** eduportal-mfe-maintenance  
> **Puerto Local:** `4208`  
> **Tecnología:** Angular 22 Zoneless + Native Federation (`@angular-architects/native-federation`)  
> **Exportación:** `./routes` vía `remoteEntry.json`  
> **Repositorio:** [https://github.com/felixxchacaliaza/eduportal-mfe-maintenance](https://github.com/felixxchacaliaza/eduportal-mfe-maintenance)  

### 🚀 Arranque Autónomo
```bash
npm install --legacy-peer-deps
npm start
```
Navega a `http://localhost:4208` para acceder al microfrontend en modo aislado.
